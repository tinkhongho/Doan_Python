## Hướng dẫn cài đặt
1. Cài đặt các thư viện: `pip install mysql-connector-python tkcalendar `
2. Import file `database.sql` hoặc execute file `sql_mysql` vào MySQL Workbench (nếu dùng MySQL) hoặc không (file đã có code tạo database nếu chưa có).
3. Chạy file `app_qlgiaovien_mysql.py` để mở phần mềm.
